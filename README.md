## 🎯 Project Overview

In today's educational landscape, understanding the nuances of student behavior is crucial for fostering success. This project addresses the challenge of identifying at-risk students early and accurately. Traditional methods often rely on lagging indicators like final grades. Our approach uses predictive analytics to provide proactive insights.

We utilize a rich dataset encompassing student demographics, academic performance, and behavioral data to train a suite of machine learning and deep learning models. The ultimate goal is to create a robust tool that empowers educators to:
*   **Identify** at-risk students before they fall behind.
*   **Understand** the key factors driving student success and failure.
*   **Implement** targeted, data-driven intervention strategies.
*   **Visualize** complex trends through an interactive Power BI dashboard.

## ✨ Key Features

*   **Multi-Model Approach**: Implements and compares various algorithms, including Random Forest, Gradient Boosting, and Deep Neural Networks (LSTMs, ANNs).
*   **High Accuracy**: Achieves prediction accuracy up to **93%** on identifying student outcomes (e.g., Dropout, Enrolled, Graduate).
*   **Feature Engineering**: Advanced preprocessing pipeline to handle missing data, scale features, and encode categorical variables effectively.
*   **Explainable AI (XAI)**: Uses SHAP (SHapley Additive exPlanations) to interpret model predictions, making the results transparent and actionable for educators.
*   **Interactive Visualization**: A comprehensive Power BI dashboard for real-time monitoring and exploration of student data and model predictions.
*   **Modular & Scalable**: Code is structured for easy extension, maintenance, and deployment.
